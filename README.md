# Timebank Landing

Public landing page for Kottakkal Time Bank, built with Next.js 15, React 19, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

See [DEPLOYMENT.md](DEPLOYMENT.md) for Vercel settings.
